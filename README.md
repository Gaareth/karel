# Karel Enhanced :^)
Adds support for Expressions, Variables, Function arguments and return values

Fork of: https://github.com/fredoverflow/karel
This is just a fun experiment, so this will probably stay behind the original repo. Nevertheless, this should still be usable in its current state.

## Limitations (currently)
- no floating point numbers
- no recursive functions
  - (you can't use functions with arguments before declaring them)
  - (Reason: I am type checking during parsing :/)
- Function calls can't have variables as arguments (YaY they now can!!)
